# Information Security Policy

All employees must use the company-approved password manager to store
credentials. Passwords must be at least 16 characters and unique per service.
Reusing passwords across systems is prohibited.

Multi-factor authentication (MFA) is mandatory for all internal systems,
including email, the VPN, and the source-control platform. Hardware security
keys are the preferred second factor; authenticator apps are acceptable.

Company data classified as Confidential or Restricted must never be copied to
personal devices or personal cloud storage. Use the corporate device management
profile and approved storage only.

Security incidents must be reported to the security team within one hour of
discovery via the incident hotline or the #security-incidents channel. Do not
attempt to remediate a suspected breach alone.
